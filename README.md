### 🟠🟡🟢 How to Use
1. Download the [Scriptable](https://apps.apple.com/cn/app/scriptable/id1405459188) App on your iPhone (ensure your system is updated to iOS 14+). 
2. Open the App, tap the + sign in the top right corner, and copy the corresponding code from the project.  
3. Long press on your home screen, add a widget, select `Scriptable`, tap widget settings, and select the script you just saved.
4. Enjoy!
